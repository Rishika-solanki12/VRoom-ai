# 🚀 VRoom AI — AI-Powered Interview Preparation Platform

**Practice. Improve. Get Hired.**

VRoom AI is an AI-powered interview preparation and career development platform designed to help job seekers improve their technical knowledge, communication skills, coding abilities, and resume quality in one place.

The platform combines AI-driven feedback, mock interview practice, resume analysis, and coding exercises to help candidates prepare for real-world job interviews.

## ✨ Features

### 🎤 AI Mock Interviews
- Practice AI-powered mock interviews.
- Experience voice-based interview conversations.
- Answer questions related to technical concepts, coding, communication, and your resume.
- Receive feedback to identify areas for improvement.
- Practice in English, Hindi, and Hinglish.

### 💻 Coding Practice
- Practice coding problems to strengthen problem-solving skills.
- Write and execute code using the integrated coding environment.
- Get AI-assisted code reviews and suggestions.
- Improve your understanding of coding concepts and solutions.

### 📄 Resume Analyzer
- Upload your resume for AI-powered analysis.
- Evaluate resume quality and identify areas for improvement.
- Review your resume score and suggestions.
- Save uploaded resumes and revisit them later.
- Analyze updated resumes for different job opportunities.

### 🗣️ Communication Practice
- Improve your spoken communication and interview confidence.
- Practice conversations with AI-powered virtual characters.
- Identify mistakes and learn how to express your thoughts more effectively.
- Review feedback to improve your communication skills.

### 🔐 Authentication
- Firebase Authentication for user sign-in and registration.
- Email verification to help protect user accounts.
- Firebase-based user identity management.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

You will also need the API keys and service configuration required by the features you want to run.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rishika-solanki12/VRoom-ai.git
```

**2. Navigate to the project directory**

```bash
cd VRoom-ai
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file in the project root and add the environment variables required by your current implementation.

For example:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Configure Firebase, Supabase, and other required services according to your project's setup.

**Important:** Never commit API keys, service account credentials, or other secrets to GitHub.

**5. Start the development server**

```bash
npm run dev
```

**6. Open the application**

Visit:

```text
http://localhost:3000
```

## 🔒 Security

- Keep API keys and secrets in environment variables.
- Never upload `.env.local` or other files containing secrets.
- Configure authentication and database access policies appropriately.
- Validate and authorize requests on the server side.
